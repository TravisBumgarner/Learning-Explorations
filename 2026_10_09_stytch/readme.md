# Stytch, OAuth and OIDC

Two localhost apps for learning how one app logs you in to another with Stytch.

- **Trav's Page** (`consumer/`, http://localhost:5273) is the identity provider.
- **Color Colors** (`provider/`, http://localhost:5274) is the client that offers "Log in from Trav's page".

Presentation: [How one app logs you in to another](https://claude.ai/artifact/5sxMXh9Q6SyLqH8vR8rELb)

## Running

```sh
npm run setup
npm run dev
```
